## 🧩 Introduction

In small and medium-sized restaurants, managing customer flow manually often leads to confusion, delays, and inefficiency.  
This project provides a **lightweight offline solution** using C language to automate:
- Table allocation
- Queue management (FIFO)
- Automatic reassignment of tables
- Real-time display of restaurant status

The system uses **arrays and linked lists** to simulate real-world restaurant operations efficiently.

---

## ✨ Features

✅ Automated table allocation and release  
✅ Dynamic customer queue using linked lists  
✅ FIFO (First-In-First-Out) queue logic  
✅ Real-time table and queue status display  
✅ Customer search by name  
✅ Color-coded console interface for better clarity  
✅ Robust input validation
